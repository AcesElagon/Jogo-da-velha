# Jogo da Velha 3D

Jogo da velha em um cubo 3×3×3, feito com Three.js em um único arquivo (`index.html`).

- **Jogar:** clique numa esfera para marcar X ou O. Vence quem fizer 3 em linha em qualquer direção (49 linhas possíveis, incluindo as diagonais que atravessam o cubo).
- **Vértices maleáveis:** arraste as esferas amarelas dos 8 vértices para deformar o cubo; a grade e as casas acompanham a deformação. Há botões para "Deformar" aleatoriamente e "Restaurar cubo".
- **Câmera:** arraste para girar, roda do mouse/pinça para zoom (até bem longe), botão direito para mover. "Ver de longe" afasta a câmera suavemente.
- **Modos:** 2 jogadores ou contra o computador. A opção "Centro bloqueado" (ligada por padrão) evita que quem começa vença facilmente pegando o centro.

Para jogar, abra `index.html` no navegador (precisa de internet para carregar o Three.js do CDN).
